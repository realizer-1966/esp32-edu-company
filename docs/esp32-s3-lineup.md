# ESP32-S3 고급 개발보드 라인업

## Overview

기존 ESP32 DevKit 기반 키트에서 한 단계 업그레이드하여, 디스플레이와 마이크가 통합된 ESP32-S3 고급 개발보드를 사용합니다. 이는 헬스케어 디바이스 개발에 최적화된 사양입니다.

---

## 1. ESP32-S3 개발보드 비교

### 1.28 인치 원형 터치 LCD 보드

#### 스펙
| 항목 | 사양 |
|------|------|
| **MCU** | ESP32-S3 (Dual-core 240MHz) |
| **디스플레이** | 1.28 인치 원형 TFT LCD |
| **해상도** | 240x240 픽셀 |
| **터치** | 정전식 터치 (GFT911) |
| **센서** | 6 축 IMU (가속도계 + 자이로) |
| **마이크** | 디지털 마이크 (I2S) × 1 |
| **메모리** | 8MB PSRAM, 4MB Flash |
| **배터리** | Li-Po 충전 회로 내장 |
| **연결성** | WiFi 4, Bluetooth 5 (BLE) |
| **크기** | 45mm 직경 (원형) |
| **가격** | 25,000 원 |

#### 장점
- **웨어러블 최적화**: 원형 디자인으로 시계형 디바이스에 적합
- **IMU 내장**: 별도 가속도계 불필요 (공간 절약)
- **터치 디스플레이**: 버튼 없이 직관적 UI
- **저전력**: AMOLED 대비 전력 소모 적음

#### 단점
- **화면 작음**: 복잡한 정보 표시 어려움
- **마이크 1 개**: 빔포밍/노이즈 캔슬링 불가

#### 헬스케어 응용
- 스마트 밴드/워치
- 심박/수면 모니터링
- 활동량 트래커
- 알림/알람 디바이스

## 6. 프로젝트 예제

### 예제 1: 심박수 워치 (1.28 인치)

```cpp
#include <TFT_eSPI.h>
#include <MAX30102.h>

TFT_eSPI tft;
MAX30102 sensor;

void setup() {
  tft.init();
  sensor.begin();
  
  // 원형 UI: 심박수 중앙 표시
  tft.fillCircle(120, 120, 100, TFT_BLACK);
  tft.setTextColor(TFT_GREEN);
  tft.setTextSize(4);
}

void loop() {
  int bpm = sensor.readHeartRate();
  
  tft.setCursor(80, 110);
  tft.print(bpm);
  tft.print(" BPM");
  
  delay(1000);
}
```

### 예제 2: 음성 건강 비서 (4 인치)

```cpp
#include <LovyanGFX.h>
#include <I2S.h>
#include <ESPSpeech.h>

LGFX lcd;
ESPSpeech speech;

void setup() {
  lcd.init();
  speech.begin(2); // 듀얼 마이크
  
  lcd.setCursor(0, 0);
  lcd.print("음성 건강 비서");
  
  // 음성 명령 등록
  speech.addCommand("심박수");
  speech.addCommand("혈압");
  speech.addCommand("오늘 날씨");
}

void loop() {
  String command = speech.listen();
  
  if (command == "심박수") {
    int bpm = readHeartRate();
    lcd.printf("심박수: %d BPM", bpm);
  }
}
```

### 예제 3: AI 수면 코치 (AMOLED)

```cpp
#include <AMOLED_Display.h>
#include <TensorFlowLite.h>
#include <MAX30102.h>

AMOLED display;
tflite::MicroInterpreter interpreter;
MAX30102 sensor;

SleepStage predictSleep(uint32_t* hrData, int len) {
  // 입력 데이터 설정
  interpreter.input(0)->data.f = hrData;
  
  // 추론
  interpreter.Invoke();
  
  // 출력: 깨어있음/얕은수면/깊은수면/REM
  float* output = interpreter.output(0)->data.f;
  return (SleepStage)argmax(output, 4);
}

void loop() {
  uint32_t hrData[60]; // 1 분 심박 데이터
  
  for (int i = 0; i < 60; i++) {
    hrData[i] = sensor.readHeartRate();
    delay(1000);
  }
  
  SleepStage stage = predictSleep(hrData, 60);
  
  // AMOLED 에 수면 단계 표시
  display.drawSleepStage(stage);
}
```
