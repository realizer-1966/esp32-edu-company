# ESP32 EduTech - 사업 계획서

## 회사 개요

**회사명**: ESP32 EduTech (가칭)  
**설립일**: 2026 년  
**비전**: "모든 학생이 IoT 개발자가 될 수 있다"  
**미션**: ESP32 기반 교육용 키트를 통해 하드웨어 프로그래밍 장벽을 낮추고, 창의적인 IoT 프로젝트 경험을 제공

---

## 시장 기회

### 문제 정의
1. **진입 장벽**: Arduino, ESP32 등 임베디드 개발은 초보자에게 어려움
2. **불완전한 학습 자료**: 이론과 실습이 분리된 교육 과정
3. **고가의 장비**: 산업용 개발 키트는 가격이 비쌈
4. **缺乏한 한국어 자료**: 한국어로 된 체계적인 IoT 교육 콘텐츠 부족

### 타겟 시장
- **주타겟**: 중학생, 고등학생, 대학생 (13-25 세)
- **부타겟**: IoT 취미 개발자, 코딩 교육 기관, 메이커 스페이스
- **시장 규모**: 국내 코딩 교육 시장 연 1 조원+, 글로벌 IoT 교육 시장 연 50 억 달러

## 제품 라인업

### 1. Starter Kit (입문자용)
**가격**: 49,000 원  
**구성**:
- ESP32 DevKit V1 메인보드
- 브레드보드 + 점퍼 와이어 세트
- 기본 센서 10 종 (온도, 습도, 조도, 적외선, 초음파 등)
- LED, 버튼, 저항, 커패시터 등 기본 부품
- USB 케이블 (Micro USB)
- 전용 케이스 (3D 프린팅)

**학습 프로젝트**:
1. LED 점등/깜빡임
2. 버튼 입력 처리
3. 센서 값 읽기
4. WiFi 연결
5. 웹 서버 만들기

### 2. Advanced Kit (중급자용)
**가격**: 89,000 원  
**구성**:
- Starter Kit 전체 구성품
- ESP32-CAM (카메라 모듈)
- OLED 디스플레이 (0.96 인치)
- 서보 모터 + 드라이버
- 릴레이 모듈
- 블루투스 스피커 모듈
- 18650 배터리 홀더

**학습 프로젝트**:
1. 카메라 이미지 캡처
2. 디스플레이 정보 표시
3. 모터 제어
4. 블루투스 오디오 스트리밍
5. 배터리 구동 프로젝트

### 3. IoT Smart Home Kit (심화용)
**가격**: 129,000 원  
**구성**:
- Advanced Kit 전체 구성품
- ESP32 메인보드 2 개 추가 (총 3 개)
- MQTT 브로커 가이드
- 스마트폰 앱 연동 가이드
- 클라우드 연동 샘플 (AWS IoT / Blynk)

**학습 프로젝트**:
1. MQTT 기반 디바이스 통신
2. 스마트폰 앱 연동
3. 음성 제어 (Google Assistant / Alexa)
4. 자동화 규칙 설정
5. 데이터 로깅 및 분석

## 교육 커리큘럼

### Level 1: 기초 (Starter Kit)
- **기간**: 4 주 (주 2 회, 2 시간)
- **내용**:
  - 주 1: ESP32 소개 + LED 제어
  - 주 2: 센서 읽기 + 시리얼 통신
  - 주 3: WiFi 연결 + 웹 서버
  - 주 4: 최종 프로젝트 (자동화 시스템)

### Level 2: 중급 (Advanced Kit)
- **기간**: 6 주
- **내용**:
  - 주 1-2: 카메라 + 디스플레이
  - 주 3-4: 모터 + 액츄에이터
  - 주 5: 블루투스 + 오디오
  - 주 6: 통합 프로젝트 (스마트 로봇/카메라)

### Level 3: 고급 (IoT Smart Home Kit)
- **기간**: 8 주
- **내용**:
  - 주 1-2: MQTT 프로토콜
  - 주 3-4: 클라우드 연동
  - 주 5-6: 스마트폰 앱 개발
  - 주 7: 음성 제어
  - 주 8: 최종 프로젝트 (스마트홈 시스템)
