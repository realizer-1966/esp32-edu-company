## 2. 낙상 감지기 (Fall Detector)

### 개요
- **난이도**: 고급
- **제작 시간**: 8-10 시간
- **비용**: 70,000 원

### 기능
- 실시간 자세 모니터링
- 낙상 패턴 감지 (머신러닝)
- 자동 119 신고 (GPS 위치 전송)
- 보호자 SMS/앱 알림
- SOS 버튼 (수동 호출)

### 하드웨어 구성
| 부품 | 수량 | 비고 |
|------|------|------|
| ESP32 | 1 개 | 메인 컨트롤러 |
| MPU6050 | 1 개 | 6 축 IMU |
| NEO-6M GPS | 1 개 | 위치 추적 |
| GSM 모듈 (SIM800L) | 1 개 | SMS/전화 |
| Li-Po 1000mAh | 1 개 | 배터리 |
| 방수 케이스 | 1 개 | 목걸이/허리 부착 |

### 낙상 감지 알고리즘
```cpp
bool detectFall() {
  // 1. 가속도 급변 감지 (> 3G)
  if (accelMagnitude > 3.0) {
    // 2. 충격 후 무동작 (10 초)
    delay(10000);
    if (isMotionless()) {
      // 3. 자세 이상 (수평/역방향)
      if (isAbnormalPosture()) {
        return true; // 낙상 확인
      }
    }
  }
  return false;
}

// 머신러닝 모델 (TensorFlow Lite)
// 과거 데이터로 학습된 낙상 패턴 분류
```

### 알림 시스템
```cpp
void sendAlert() {
  // SMS 전송
  gsm.sendSMS("보호자번호", "낙상 감지! 위치: " + gpsLocation);
  
  // 119 전화 (3 회 시도)
  for (int i = 0; i < 3; i++) {
    gsm.call("119");
    delay(5000);
  }
  
  // 클라우드 알림
  sendToCloud("FALL_DETECTED", gpsLocation);
}
```

### 상업화 가능성
- **타겟**: 65 세 이상 노인, 치매 환자
- **가격**: 150,000 원 (월 10,000 원 서비스료)
- **유통**: 요양원, 노인복지관, 온라인
- **인증**: MFDS Class I (의료기기 신고)


## 개발 팁

### 1. 생체신호 처리
- **필터링**: 저역통과 (0.5-40Hz), 고역통과 (0.5Hz)
- **노이즈 제거**: 50/60Hz 노치 필터 (전원 노이즈)
- **피크 감지**: Pan-Tompkins 알고리즘 (ECG)

### 2. 저전력 설계
- **Deep Sleep**: 10-20 μA 소비
- **간헐 측정**: 1 분마다 1 초 측정
