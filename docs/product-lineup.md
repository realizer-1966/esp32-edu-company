# 제품 라인업

## Overview

ESP32 EduTech 는 3 단계 제품 라인업으로 초보자부터 고급자까지 체계적인 학습 경로 제공

---

## 1. Starter Kit (입문자용)

### 제품 정보
- **제품명**: ESP32 Starter Kit V1
- **모델넘버**: ESK-001
- **가격**: 49,000 원 (VAT 포함)
- **타겟**: 중학생 이상, 코딩 처음 시작하는 대학생
- **추천 연령**: 13 세+

### 패키지 구성

#### 메인 보드
| 항목 | 수량 | 비고 |
|------|------|------|
| ESP32 DevKit V1 | 1 개 | WiFi + 블루투스, 30 핀 |
| USB 케이블 (Micro) | 1 개 | 1m, 데이터 전송 지원 |

#### 기본 부품
| 항목 | 수량 | 비고 |

| 브레드보드 (400 포인트) | 1 개 | 표준 사이즈 |

| 전해 커패시터 | 5 개 | 10uF 3, 100uF 2 |

#### 센서 모듈
| 항목 | 수량 | 비고 |

| 케이스 (3D 프린팅) | 1 개 | 부품 정리함 |

### 학습 프로젝트 (10 개)

1. **LED 점등하기** - GPIO 출력 기초
2. **LED 깜빡이기** - 타이밍 제어
3. **버튼으로 LED 제어** - GPIO 입력
4. **PWM 으로 LED 밝기 조절** - 아날로그 출력
5. **DHT11 으로 온습도 측정** - 디지털 센서
6. **조도 센서로 자동 LED** - 아날로그 입력
7. **초음파 센서로 거리 측정** - 펄스 측정
8. **서보 모터 제어** - 각도 제어
9. **WiFi 연결하기** - 네트워크 기초
10. **웹 서버 만들기** - IoT 기초

### 기술 스펙
- **ESP32**: Dual-core 240MHz, 520KB SRAM, WiFi 802.11 b/g/n, BT 4.2
- **전원**: 5V (USB) / 7-12V (배터리)
- **동작 온도**: 0-60°C
- **크기**: 25cm x 18cm x 5cm (케이스 포함)
- **무게**: 400g

### 소프트웨어
- **IDE**: Arduino IDE 2.x, PlatformIO
- **언어**: C/C++ (Arduino Framework)
- **라이브러리**: ESP32 Arduino Core
- **예제 코드**: GitHub 공개

## 2. Advanced Kit (중급자용)

### 제품 정보
- **제품명**: ESP32 Advanced Kit V1
- **모델넘버**: EAK-001
- **가격**: 89,000 원 (VAT 포함)
- **타겟**: 고등학생, 대학생, IoT 취미 개발자
- **추천 연령**: 16 세+
- **전제조건**: Starter Kit 완료 또는 동등 지식

### 패키지 구성

#### Starter Kit 전체 구성품 포함

#### 추가 모듈
| 항목 | 수량 | 비고 |
|------|------|------|
| ESP32-CAM | 1 개 | OV2640 카메라, microSD |
| OLED 디스플레이 (0.96") | 1 개 | I2C, 128x64 |
| 블루투스 스피커 모듈 | 1 개 | 3W, 클래스 D |
| 18650 배터리 홀더 | 1 개 | 1 셀, 스위치 포함 |
| Li-ion 배터리 (18650) | 1 개 | 2000mAh, 보호회로 |
| 모터 드라이버 (L298N) | 1 개 | 듀얼 H-브리지 |
| 스텝 모터 (28BYJ-48) | 1 개 | 5V, ULN2003 포함 |
| LCD 디스플레이 (1602) | 1 개 | I2C 어댑터 포함 |
| RTC 모듈 (DS3231) | 1 개 | 실시간 시계 |
| SD 카드 모듈 | 1 개 | SPI |
| NFC 모듈 (RC522) | 1 개 | RFID |
| 자이로 센서 (MPU6050) | 1 개 | 6 축 |
| 기압 센서 (BMP180) | 1 개 | I2C |
| 심박 센서 (MAX30100) | 1 개 | PPG |
| GPS 모듈 (NEO-6M) | 1 개 | 안테나 포함 |
| 적외선 리모컨 + 수신기 | 1 세트 | NEC 프로토콜 |
| 엔코더 모듈 | 1 개 | 로터리 |
| 터치 센서 (TTP223) | 2 개 | capacitive |
| RGB LED 스트립 (WS2812B) | 1 개 | 1m, 60LED |
| 케이스 (확장형) | 1 개 | 2 단 |

### 학습 프로젝트 (15 개)

1. **OLED 에 텍스트 표시** - I2C 통신
2. **카메라 이미지 캡처** - ESP32-CAM
3. **SD 카드에 데이터 저장** - 파일 시스템
4. **RTC 로 시간 표시** - I2C 시계
5. **NFC 태그 읽기/쓰기** - RFID
6. **자이로로 기울기 측정** - 6 축 센서
7. **GPS 로 위치 추적** - NMEA 파싱
8. **심박수 측정** - 생체 신호
9. **기압으로 고도 측정** - 환경 센서
10. **블루투스로 음악 재생** - A2DP
11. **적외선 리모컨 제어** - IR 프로토콜
12. **터치 센서로 인터페이스** - capacitive
13. **LED 스트립 애니메이션** - WS2812B
14. **스텝 모터 정밀 제어** - 각도/속도
15. **배터리 구동 프로젝트** - 전원 관리

### 기술 스펙
- **추가 스펙**: 카메라 2MP, OLED I2C, 블루투스 A2DP
- **배터리**: 18650 Li-ion 2000mAh, 3.7V
- **동작 시간**: 4-8 시간 (프로젝트별)
- **충전**: 별도 충전기 필요 (또는 USB)

2. **Publish/Subscribe 기초**
3. **여러 디바이스 통신**

#### 클라우드 연동
4. **AWS IoT Core 연결**
5. **Blynk 앱 연동**
6. **Thingspeak 데이터 로깅**
7. **IFTTT 연동**

#### 스마트홈 프로젝트
8. **스마트 조명 시스템**
9. **자동 커튼 제어**
10. **온도 기반 에어컨 제어**
11. **도어락 시스템**
12. **보안 시스템 (모션/도어)**
13. **스마트 플러그 제어**
14. **가스/연기 경보**
15. **물 누수 감지**

#### 고급 기능
16. **음성 제어 (Google Assistant)**
17. **음성 제어 (Alexa)**
18. **스마트폰 앱 개발** (MIT App Inventor)
19. **웹 대시보드** (React/Vue)
20. **자동화 규칙 엔진**

### 기술 스펙
- **프로토콜**: MQTT, HTTP, WebSocket, Zigbee, LoRa
- **클라우드**: AWS IoT, Blynk, Thingspeak, IFTTT
- **음성**: Google Assistant, Alexa 연동
- **앱**: Android/iOS 연동
