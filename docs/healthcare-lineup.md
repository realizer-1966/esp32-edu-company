# 헬스케어 디바이스 라인업

## Overview

ESP32 EduTech 의 헬스케어 디바이스 라인은 교육용 키트를 기반으로 하여 개인 건강 모니터링, 원격 환자 관리, 웰니스 트래킹 등의 응용 디바이스를 개발할 수 있습니다.

---

## 확장 가능성

### ESP32 의 헬스케어 적합성

#### 기술적 장점
| 기능 | 헬스케어 응용 |
|------|-------------|
| **WiFi/블루투스** | 건강 데이터 클라우드 동기화, 스마트폰 연동 |
| **저전력 모드** | 웨어러블 디바이스 장시간 구동 |
| **ADC (아날로그 입력)** | 생체 신호 (심전도, 근전도) 증폭/측정 |
| **I2C/SPI 통신** | 의료 센서 모듈 연결 |
| **작은 사이즈** | 웨어러블/휴대용 디바이스 제작 |
| **저렴한 가격** | 대량 생산/교육용 접근성 |

#### 인증 고려사항
- **교육/연구용**: 의료기기 인증 불필요 (연구/취미 목적)
- **상업용**: MFDS 의료기기 인증 필요 (Class I/II)
- **권장**: "웰니스 디바이스" 포지셔닝 (의료 진단 목적 아님)

## 4. Healthcare Kit (헬스케어 특화)

### 제품 정보
- **제품명**: ESP32 Healthcare Kit V1
- **모델넘버**: EHK-001
- **가격**: 159,000 원 (VAT 포함)
- **타겟**: 의대생, 바이오공학과, 헬스케어 스타트업, 연구자
- **추천 연령**: 18 세+
- **전제조건**: Advanced Kit 완료 또는 생체신호 기초 지식

### 학습 프로젝트 (25 개)

#### 기초 생체신호
1. **심박수 측정** (PPG 원리)
2. **혈중산소포화도 (SpO2)** 계산
3. **심전도 (ECG) 기록** - 1 리드
4. **근전도 (EMG) 측정** - 근육 수축
5. **체온 모니터링** - 비접촉식
6. **호흡수 측정** - 스트레인 게이지

#### 웨어러블 디바이스
7. **스마트 밴드 만들기** - 심박/걸음수
8. **수면 모니터링** - 가속도계 + 심박
9. **스트레스 지수** - HRV 분석
10. **칼로리 소모 계산** - 활동량 + 심박
11. **자세 교정 디바이스** - 자이로/가속도계

#### 원격 건강 관리
12. **블루투스로 스마트폰 연동** - BLE GATT
13. **클라우드 건강 기록** - AWS/Azure
14. **보호자 알림 시스템** - 이상 징후 감지
15. **텔레메디슨 데이터 포맷** - HL7/FHIR 기초
16. **모바일 앱 개발** - Flutter/React Native

#### 특화 응용
17. **노인 낙상 감지** - 가속도계 + AI
18. **만성질환 관리** - 당뇨/고혈압 트래킹
19. **재활 운동 모니터링** - EMG + 각도
20. **수면 무호흡 감지** - 호흡 + SpO2
21. **운동 강도 최적화** - 심박존 분석
22. **탈수 경고 시스템** - 땀 센서
23. **자외선 경고** - UV 센서
24. **약 복용 알림** - NFC + 앱
25. **통합 건강 대시보드** - 웹/모바일

### 기술 스펙
- **생체신호 샘플링**: ECG 250Hz, PPG 100Hz, EMG 500Hz
- **정확도**: 심박 ±2bpm, SpO2 ±2%, 체온 ±0.1°C
- **배터리**: 500mAh Li-Po, 24-48 시간 구동
- **충전**: USB-C, 2 시간 완충
- **방수**: IP54 (땀/비 방지)
- **데이터 저장**: microSD 32GB (약 30 일분)
- **연결성**: WiFi, Bluetooth 5.0 (BLE)

### 소프트웨어
- **생체신호 처리**: 필터 (저역/고역), 피크 감지
- **HRV 분석**: SDNN, RMSSD, LF/HF ratio
- **머신러닝**: TensorFlow Lite for MicroControllers
- **앱 연동**: MIT App Inventor, Flutter 예제
- **클라우드**: AWS IoT, Google Cloud Healthcare API

## 5. 의료기기 개발 가이드 (별冊)

### 의료기기 분류 (한국 MFDS 기준)

#### Class I (위험도 낮음)
- **예시**: 보조기구, 단순 측정기
- **인증**: 제조/수입 신고
- **기간**: 3-6 개월
- **비용**: 500-1,000 만원

#### Class II (위험도 중간)
- **예시**: 혈압계, 체온계, 심박계
- **인증**: 제조/수입 허가
- **기간**: 6-12 개월
- **비용**: 2,000-5,000 만원

#### Class III/IV (위험도 높음)
- **예시**: 심전계, 제세동기, 인공호흡기
- **인증**: 제조/수입 허가 (엄격)
- **기간**: 12-24 개월
- **비용**: 5,000 만원 - 2 억원

### 권장 개발 경로

#### 단계 1: 연구/교육용 (인증 불필요)
- **목적**: 프로토타입, 검증, 논문
- **표시**: "연구용 only", "의료 진단 목적 아님"
- **판매**: 대학, 연구소, 메이커

#### 단계 2: 웰니스 디바이스 (인증 간소화)
- **목적**: 일반 소비자 건강 관리
- **표시**: "웰니스 목적", "진단/치료 목적 아님"
- **판매**: 온라인, 오프라인 매장

#### 단계 3: 의료기기 (인증 필요)
- **목적**: 질병 진단/치료/모니터링
- **표시**: MFDS 인증 마크
- **판매**: 병원, 약국, 의료기기 매장

### 국제 인증

| 인증 | 지역 | 내용 |
|------|------|------|
| **CE** | 유럽 | 의료기기 적합성 |
| **FDA 510(k)** | 미국 | 시판 전 신고 |
| **ISO 13485** | 국제 | 의료기기 품질 경영 |
| **IEC 60601** | 국제 | 의료전기기기 안전 |

## 헬스케어 응용 사례

### 1. 만성질환 관리 시스템

#### 당뇨 관리
- **연속 혈당 모니터링 (CGM)** 연동
- **인슐린 펌프** 제어 (연구용)
- **식단/운동 기록** 앱 연동
- **저혈당 경고** 알림

#### 고혈압 관리
- **연속 혈압 모니터링**
- **복약 관리** 알림
- **생활습관 코칭**
- **의사 공유 리포트**

### 2. 노인 케어 디바이스

#### 낙상 감지
- **가속도계/자이로** 실시간 모니터링
- **이상 패턴 감지** (머신러닝)
- **자동 119 신고** (GPS 위치 전송)
- **보호자 알림** (SMS/앱)

#### 치매 예방
- **일상 활동 패턴** 분석
- **배회 감지** (GPS 펜싱)
- **약 복용 관리**
- **인지 훈련 게임**

### 3. 스포츠/피트니스 트래커

#### 전문 운동 분석
- **근전도**로 근육 활성화 분석
- **자이로**로 자세 교정
- **심박존** 기반 강도 조절
- **회복 시간** 추천

#### 개인 맞춤 코칭
- **기초대사량** 계산
- **목표 심박수** 설정
- **칼로리 소모** 정확 측정
- **수면 질** 분석

### 4. 원격 환자 모니터링 (RPM)

#### 병원 연동
- **퇴원 환자** 가정 모니터링
- **실시간 건강 데이터** 전송
- **이상 징후** 자동 알림
- **텔레메디슨** 연동

#### 데이터 표준
- **HL7 FHIR** 의료 데이터 포맷
- **DICOM** 의료 영상 (연동)
- **SNOMED CT** 임상 용어
